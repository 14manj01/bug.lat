Skyrim Worldspace MCP

A Model Context Protocol server exposing 80 tools that let AI models generate Skyrim Special Edition worlds: terrain quilted from vanilla landscape pieces, rivers and waterfalls, terrain-driven biomes, transplanted towns, learned road and site plans, generated caves, and navmesh. Output is verified with Mutagen and inspected in an isolated Creation Kit sandbox.
